\section{Project Outcome Plan}
\label{projectChoice:ProjectOutcomePlan}
The aim for my EP artifact is to produce a piece of software fundamentally designed for students to record their notes and learnings In a classroom environment in the most effective way to promote long term acquisition of material.

The application will be a "web-app" that can run on any web browser across all of the users devices

This is my goal for the simple yet highly functional view of the note editor where users are able to add a variety of 'components' to record their notes in a well thought through way.

Here is a feature List I want to achieve:
\begin{itemize}
    \item Users able to register and login to their accounts
    \item Ability to view a list of notes in a graphical view that shows connections through tags
    \item Ability to filter / search through notes and tags to find the content desired quickly
    \item Creation of 2 note types: whiteboards (for handwritten notes / diagrams) and documents (for typed out notes)
    \item In depth linking to whiteboards inside of typed documents
    \item Ability to easily add resources such as screenshots, youtube videos, dedicated resources (potential PMT and SaveMyExams links) and written notes to documents
    \item Format Code, Maths and Chemical equations nicely.
    \item Share Notes to common file standards: Plaintext (raw text content), Markdown (text with embellishments such as bold italics etc), PDF (full mixed media notes)
    \item AI tools for content writing, summaries and tag allocation to easily organise content  
\end{itemize}
