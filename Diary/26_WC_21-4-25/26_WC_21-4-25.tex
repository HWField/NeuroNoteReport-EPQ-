Towards the end of the week I was showing my friends my recent progress and had a couple of pieces of feedback given. Firstly when showing my document editor the wording of the tool to change the pen properties became confusing. It was a pen icon followed by "type". To me this was indicating pen type (e.g. fine, thick etc) however to him it indicated an area to type in a command, I have changed the wording now to width however this has been a valuable learning point that what is in my head isn't necessarily the most obvious interpretation 

My second feedback came whilst speaking to a friend who has differing visual needs. He prefers having his laptop display magnified to make elements easier to read. Whilst the various text and images around my interface scaled perfectly (in line with my accessibility research), the method his browser used to scale the screen didn't correctly scale the dashboards banner, thus it became too large and covered 1/3rd of the display which isn't intended behaviour. To fix this I have slightly altered the code which calculates the banner size so that it entirely prioritises seeing all of the options/buttons and text
