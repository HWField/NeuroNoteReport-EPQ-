\section{Project Breakdown}

\subsection{A01 Planning:}
\begin{enumerate}
    \item Plan time use across the EPQ project
    \item Create a skills' development plan
    \item Create project breakdown (here)
    \item Create a mind map using initial project ideas
    \item Decide on a project topic
    \item Create a detailed (and ongoing) goal sheet 
    \item Produce task sheets for each 'extended' EPQ day
\end{enumerate}
\subsection{A02 Human Research::}
\begin{enumerate}
\item Research memory learning techniques
\item Research note-taking strategy's
\item Complete primary research by gauging demand for different types of research methods
\item Research colour theory and visual hierarchy
\item Research UX (User experience) design trends and best practices
\item Complete further primary research using past learnings to produce demos that can be a / b chosen by volunteers
\end{enumerate}
\subsection{A02 Technical Research:}
\begin{enumerate}
    \item Research web hosting technologies
    \item Research web security
    \item Research real time collaboration systems
    \item Research Backend Database systems
    \item Research data visualisation and management techniques
\end{enumerate}
\subsection{A03 Development:}
\begin{enumerate}
    \item  produce a range of initial prototypes which test individual technologies
    \item Produce a range of design ideas (using tools such as Figma) which can then be reviewed by peers and others
    \item Develop final project Artifact towards end of project
    \item Develop presentation video and artifact exploration video
\end{enumerate}
\subsection{A04 Review:}
\begin{enumerate}
    \item Continually review progress against project plan
    \item Review project against success criteria
    \item Review project against initial aims and objectives
    \item Review project against EPQ assessment criteria
    \item Review project with peers, family and friends to gain feedback both before and after final artifact creation
\end{enumerate}
