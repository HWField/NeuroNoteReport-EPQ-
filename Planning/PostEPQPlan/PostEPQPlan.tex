\section{Post EPQ Plan}
\label{Planning:PostEPQPlan}
I am so proud of the platform I have produced since the start of the EPQ Program last September. I have created a platform that I can and will use day-to-day for my note-taking continuing into Upper Sixth and then into University and beyond. 

Community transparency and accessibility is a core foundation of my beliefs so to help others use the work I have built, in addition to my free to access public platform hosted on neuronote.space, I will make the source code of my project available (Open Source) on GitHub at my public repository: https://github.com/Nasebyone/EPQ. This enables anyone to use, modify and contribute to the project. I will also write a detailed README file to help users understand how to set up and use the platform for their own custom use case. 

Potentially this might inspire others to help me further develop this project, or to even use the code as a basis for their own projects and tools to help others organise their thoughts and ideas. I will also share my project on relevant online communities and forums to reach a wider audience and gather feedback.

To continue developing on the features I already have I've created a list below of some ideas I have come across throughout the development of my EPQ but have not had time to implement, but can now develop to enhance my project:

\begin{itemize}
    \item Automatic AI Processing of audio (live or pre-recorded) into nicely formatted, summarised notes
    \item Recording audio directly within the application
    \item Offline support for mobile devices, potentially even dedicated mobile applications
    \item Further enriched AI usage to help with note organisation, tagging and searching
    \item Handwriting recognition for handwritten notes and sketches
    \item More customisation options for users to tailor the application to their needs
    \item Collaboration features to allow multiple users to work on the same notes simultaneously
    \item Integration with other note-taking and productivity tools to streamline workflows
\end{itemize}

I hope to keep this project continuing to grow and evolve over time, and to help others organise their thoughts and ideas as it has helped me.
